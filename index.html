QuickJobFill 求职一键填

填一次个人资料，自动帮你填好各招聘网站的投递表单，本人确认后提交——数据不出本机。

打开界面原型体验 查看 GitHub 仓库
点浏览器右上角插件图标，面板弹出帮你填表（界面原型演示，示例数据为虚构）

核心功能

个人资料档案按分类整理求职信息，填一次，处处用
一键自动填表能确定的填好标绿，拿不准的标橙待你确认
确认后提交插件只填表、绝不代提交，数据不出本机
